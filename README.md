# bloodborne_mac has moved

This repository was the macOS port of Bloodborne, a fork of
[bbport](https://github.com/deadinside28/bloodborne_pc). It continues as three repositories:

| Repository | |
|---|---|
| [**bloodborne-mac**](https://github.com/PabloVSouza/bloodborne-mac) | The macOS app: downloads, releases, player guides ([latest release](https://github.com/PabloVSouza/bloodborne-mac/releases/latest)) |
| [**bloodborne-runtime**](https://github.com/PabloVSouza/bloodborne-runtime) | Loads the game: the PS4 libraries, the renderer (built on bbport and shadPS4) |
| [**bloodborne-recomp**](https://github.com/PabloVSouza/bloodborne-recomp) | The x86-64 → arm64 translator and the static recompiler |

The history up to the move stays here. Thank you to
[bbport](https://github.com/deadinside28/bloodborne_pc) by deadinside28 and to
[shadPS4](https://github.com/shadps4-emu/shadPS4), which all of this is built on.
